# Nx UML Viewer

Nx UML Viewer is a planned TypeScript-first architecture explorer for Nx
workspaces, with deeper understanding of Angular applications and libraries.
It will turn Nx project metadata and TypeScript/Angular relationships into an
interactive, drillable diagram without modifying the workspace being viewed.

This repository currently contains the original `uml-viewer-master/` project
as a behavioral reference. The new implementation will live at the repository
root and will not depend on its Clojure or Quil runtime.
